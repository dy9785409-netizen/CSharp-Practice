# Day 13 — Aaj maine kya seekha

Aaj maine C# mein `File.AppendAllText()` aur `File.ReadAllText()` ka use karke existing text file mein naya data add karna aur poora data read karna seekha. `File.Exists()` se file check karna bhi practice kiya.

## Aaj ka chhota task

Ek program banao jo `PracticeFiles/notes.txt` mein user ka naam aur ek short message append kare, phir file ka poora content console par print kare.
