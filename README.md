# Day 12 — Aaj maine kya seekha

Aaj maine C# mein `Directory.CreateDirectory()` aur `Directory.Exists()` ka use karke folder banana aur check karna seekha. `Path.Combine()` se safe file path banana bhi seekha.

## Aaj ka chhota task

Ek program banao jo `PracticeFiles` naam ka folder create kare, uske andar `notes.txt` file banaye, aur console par folder aur file ka path print kare.
