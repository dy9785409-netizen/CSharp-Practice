# Day 14 — Aaj maine kya seekha

Aaj maine C# mein `Directory.GetFiles()` aur `Directory.Exists()` ka use karke folder ke andar files count karna aur folder available hai ya nahi, ye check karna seekha. `Path.GetFileName()` se file ka sirf naam nikalna bhi practice kiya.

## Aaj ka chhota task

Ek program banao jo `PracticeFiles` folder ki sabhi `.txt` files dhoonde, unki total count print kare, aur har file ka naam console par show kare.
